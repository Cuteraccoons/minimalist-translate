## 观察到的结构与当前处理

选择器使用稳定前缀或语义属性；样本 JSON 中的完整哈希类名仅为观察记录，不能硬编码。

| 结构 | 定位线索 / 样本 | 当前行为与待补充要求 |
|---|---|---|
| 顶部人物背景、封面 | `posterBg_`；周杰伦 | 读取背景作为封面；需核对裁切、标题装饰及是否重复 |
| 摘要与章节正文 | `.J-lemma-content`、`para_`；全部样本 | 基础正文可读；不能把导航、视频标签混成正文 |
| 基本信息 | `.J-basic-info`、`basicInfo_`；人物、水、城市、学校 | 当前按 DT 后紧邻 DD 配对；字段计数已保留，长值、多链接、多值、隐藏展开需逐项核对 |
| 顶部目录、层级目录 | `catalog_`、`catalogWrapper_`；苹果公司、周杰伦 | 源目录主动过滤，左栏由正文标题生成；存在目标不证明层级或跳转精确 |
| 单图、图文组合 | `lemmaPicture_`、`picture_`；大熊猫、苹果公司 | 保留已加载图片；排版表格、图片归属和真实重复仍需核对 |
| 图集、合集 | `album`、`albumCollection`；故宫、中国共产党 | 已知图集转静态网格；有空图集与懒加载限制；不要导入轮播克隆 |
| 普通／合并单元格表格 | `table`、`tableBox_`；杭州、苹果公司 | 原始表格和资料表需区分；保留 rowspan/colspan、链接、图及原有色彩 |
| 音乐专辑、单曲、创作 | `musicAlbum`、`musicSingle`、`musicForOthers`；周杰伦 | 有作品卡或普通表格提取，尚无每种类型的完整语义验收 |
| 影视作品 | `movie`、`teleplay`；周杰伦 | 有海报卡提取；作品名、饰演、导演、主演需保持一张记录内的关系 |
| 综艺、演唱会、杂志、获奖 | `varietyShow`、`concert`、`magazine`、`award`；周杰伦 | 主要依赖普通结构；需验证年份、类别与作品不串行 |
| 视频 | `video`、`videoCover_`；水、光合作用、故宫 | 顶部直连视频或封面原文入口已有处理；正文视频模块未全面覆盖；播放器数量不代表可播放 |
| 地图 | `map`；清华大学 | 不恢复原站脚本；后续考虑静态预览＋原文入口，不能造空白播放器 |
| 互动图鉴、相关星图 | `dynamicWiki_`、`lemmaStructured_`、星图容器 | 用户允许跳过，不应把它们当成待恢复的全文内容 |
| 引用、参考资料 | 正文上标与末尾参考列表 | 与译文引用、链接保留一起回归；不要仅按链接密度删除 |
| 时间线／大事记 | 待确认独立组件；历史类章节见秦始皇、长征、苹果公司 | 当前只确认历史章节及日期文本，未确认独立时间轴组件。必须先补真实 DOM 样本，不能从标题推断支持 |

## 具体证据与边界

- 16 页采集的标题均在阅读器找到；大纲目标缺失数均为 0。仍需检查层级、同名标题、点击后是否被顶栏挡住。
- 苹果公司原网页 20 个表格、阅读器 12 个。额外检查发现其中 8 个原表格只有一行，是图片／图注布局，不能直接报告“丢失 8 个数据表”。后续应检查这些图片组合是否保留、位置是否正确。
- 苹果公司有至少 5 张图片同时位于阅读器表格单元格和后续独立段落，说明存在重复提取线索；详见 `baike-apple-table-audit.json`。需回到源节点确认归属，不能按图片 URL 全文去重，否则会删除合法复用图片。
- 一些页面有空图集，详见矩阵。懒加载预热只处理前 32 个目标；未加载与提取失败要区分。
- 原网页计数在预热前，阅读器计数在预热后；顶部媒体还可能在正文主容器外。不得用两个总数直接计算媒体保留率。
- 图片计数排除了按钮和扩展资源。民法典页面的大量 IMG 是段落翻译按钮图标，不是正文插图，不是媒体重复问题。
- 宽泛的时间线类名检索抓到 `dynamicWiki_`，实际为互动 iframe；不作为结构化时间轴证据。
