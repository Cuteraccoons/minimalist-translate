> **公開中：** [Chrome ウェブストア](https://chromewebstore.google.com/detail/pbndcgchimohkkdijfafhaljldgfkhbd) からインストールできます。手動インストール用のパッケージは [Releases](https://github.com/Cuteraccoons/minimalist-translate/releases/latest) でも配布しています。

極簡翻訳は、外国語の Web ページを元の構造に近い状態で読むためのオープンソース Chrome 拡張機能です。リンク、タブ、ボタン、レイアウトの関係をできるだけ保ちながら、対訳表示、リーダー表示、辞書検索、ローカル画像 OCR を追加します。

## ページに合わせて読み方を選ぶ

- **原文と訳文**：原文の下に訳文を追加し、ページ本来の構造と操作を保ちます。記事リンクのカードは原文を残したまま同じリンク内に訳文を追加し、幅の狭いタブだけをホバーで原文へ戻せる単一ラベルとして扱います。
- **原文を置換**：テキストノードだけを置き換え、リンク、ボタン、ナビゲーション、タブをそのまま操作できます。
- **集中リーダー**：本文を抽出し、重複見出しを除去し、安全なリンク、3 段階のアウトライン、全文読み上げ、紙面・フラット・コラム・見開きの 4 種類のページ構造を提供します。
- **左右対訳**：独立した対訳パネルを表示し、原文位置への移動、幅調整、段落読み上げに対応します。

## ページを離れずに辞書を引く

- Free Dictionary API、Jisho / JMdict、萌典、Wikipedia の要約を利用できます。
- ローカルの MDX / MDD 辞書と付属 CSS、画像、音声を直接読み込み、辞書ファイルをアップロードしません。
- サービスを設定すると、AI による文脈説明と追加質問を利用できます。
- 単語帳とハイライトはブラウザー内に保存され、検索、絞り込み、Markdown / CSV 出力に対応します。

## 画像内の文字をローカルで翻訳する

画像 OCR は、拡張機能に同梱された Tesseract.js を使ってブラウザー内で実行されます。言語を初めて使う際は公開モデル配布元から言語モデルを取得し、ブラウザーのキャッシュに保存します。元画像が OCR サービスへ送信されることはありません。翻訳を実行した場合のみ、認識済みのテキストが選択中の翻訳サービスへ送信されます。

翻訳後の画像は元のページ位置に残ります。認識行は元の位置へ書き戻され、隣接行との境界、文字揃え、背景とのコントラストを自動調整します。いつでも原画像へ切り替えられます。

Google 翻訳は基本エンジンとして利用できます。次のサービスはユーザー自身の設定が必要です。

- Gemini
- Ollama

## ローカルインストール

1. [Releases](https://github.com/Cuteraccoons/minimalist-translate/releases/latest) から最新パッケージをダウンロードして展開します。
2. Chrome で `chrome://extensions/` を開きます。
3. **デベロッパー モード**を有効にします。
4. **パッケージ化されていない拡張機能を読み込む**を選び、`Jijian-Translate` フォルダーを指定します。

Chrome は ZIP ファイルを直接読み込めません。ローカル版を更新する場合は同じフォルダー内のファイルを置き換え、拡張機能の管理画面で再読み込みしてください。

## データの境界

- API キー、カスタムサービスの接続先、モデル設定は現在の端末だけに保存されます。一般的な表示・読書設定は Chrome Sync で同期される場合があります。
- 単語帳、ハイライト、翻訳キャッシュ、ローカル辞書の接続情報は現在の端末に保存されます。
- ローカルの MDX / MDD 辞書ファイルはアップロードされません。
- OCR はローカルで実行され、翻訳時に限って認識済みテキストが選択中の翻訳サービスへ送信されます。
- オンライン翻訳、オンライン辞書、任意の AI リクエストには、選択したサービス提供者のポリシーが適用されます。
- 独自アカウントシステムやクラウド同期サービスはありません。

サービスと権限の詳細は [プライバシーに関する説明](PRIVACY.md) を参照してください。

## プロジェクトと応援

極簡翻訳が日々の読書に役立った場合は、[愛発電](https://www.ifdian.net/a/longmaojun) から任意で応援できます。これは公開済みのオープンソース成果に対する評価であり、専用機能、更新日程、保守の約束を購入するものではありません。
